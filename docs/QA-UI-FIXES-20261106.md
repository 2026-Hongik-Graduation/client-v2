# POFIT 운영 화면 UI 회귀 수정 — 2026-11-06

## 현상·원인
- `/interviews`: 소개 문단이 한두 음절씩 세로로 개행됨. Tailwind v4 커스텀 `--spacing-2xl:40px`이 `max-w-2xl` 유틸리티를 덮어 문단 폭이 40px이 됨.
- `/applications`: 지원 카드 추가 팝업이 폭 24px로 줄어 폼이 망가짐. `--spacing-lg:24px`이 `max-w-lg`을 덮어씀.
- `/onboarding`: 같은 `max-w-lg` 폭 충돌 가능성 발견.
- 단계별 '카드 추가하기'는 원래 어느 열을 눌러도 '지원 예정'에만 추가됨.

## 적용
- 면접 소개 문단: `max-w-[672px]`; 팝업/온보딩: `max-w-[512px]`로 명시적 너비 적용.
- 카드 팝업 높이를 뷰포트 안으로 제한하고 내용 스크롤 허용.
- 클릭한 칸반 열을 등록 모달의 기본 지원 단계로 사용. 모든 네 단계의 카드 등록·새로고침 유지 지원.
- 카드는 자소서 생성 후 단계 이동을 적용. 이동 실패 시 카드는 지원 예정에 남고 경고를 표시(부분 성공 숨기지 않음).
- 팝업 전용 오류 메시지 분리 및 등록 성공 시 필터 초기화.

## 재검증
- `npm run lint`, `npx tsc --noEmit`, `npm run build`: PASS.
- 실제 운영용 Next.js 빌드(`localhost:3003`) + 헤드리스 Chrome에서 면접 배너/카드 추가 팝업 폭 검증: 1440/992/720/390/360px, 전부 PASS.
- 4개 지원 단계(지원 예정/서류 준비/제출 완료/전형 종료)의 생성, 선택 단계, 새로고침 후 유지, 상세 진입, 면접 연동 PASS.
- 데모 모드에서 API 네트워크 호출 0건, JS 예외 0건(해당 E2E).
- 6개 페이지 × 4개 크기(1440/1023/720/360): 24/24 가로 넘침 없음.
